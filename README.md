# 3v3pr-media

3v3PR | Promoting Resilience. — media library for the 3v3PR AI team.

Public on purpose: Instagram and LinkedIn can only post images that have a public web address.

- `kit/` — ARTE's rendering kit (renderer, Red Rose font, logo)
- `posts/YYYY-MM-DD/` — finished social visuals, one language per image
- `assets/` — flyers, one-pagers and signage (EN and ES files)
- `photos/cleared/` — the only photos ARTE may use (no identifiable people without written consent)

Nothing here is deleted or rewritten by an agent.
